# Customize your developer profile

## Before publishing
1. Replace every `[Your Name]` placeholder with the name you want to display.
2. Your GitHub username is already set to `rainvictoria098-cpu` in `README.md` and `index.html`.
3. Replace `your.email@example.com` and `[Your email address]` with a public contact email, or remove those links.
4. Replace `[Your City, Country]` if you want to show a location, or remove that bullet.
5. Add real projects only. Replace the sample project placeholder with a project you actually built.
6. Do not claim skills or experience you do not yet have.

## GitHub Profile README
- Create a public repository whose name exactly matches your GitHub username.
- Upload `README.md` to the root of that repository.
- The GitHub stats images use `github-readme-stats.vercel.app`; third-party stats services can sometimes be unavailable.

## Portfolio website
- Keep `index.html`, `styles.css`, and `script.js` in the same folder.
- Open `index.html` in a browser to preview it.
- To publish it, upload these three files to a static hosting service such as GitHub Pages.
- Google Fonts requires an internet connection; the page remains usable with fallback fonts if it cannot load.
